# 键感 · 盲打练习台

一个免安装、可离线使用的中英文盲打准确度练习工具。用纯 HTML + CSS + JavaScript 实现，直接用浏览器打开即可。

> **状态：开发中（Work in Progress）**
> 项目仍在持续迭代，功能、题库、界面和计分规则都可能调整，暂未发布稳定版本。当前代码仅供参考和体验。

## 它解决什么问题

面向「已经会盲打，但写中文和英文时容易按错键、需要停下来找标点」的人。重点不是打字速度，而是**首次就把想写的字符和标点打对**。

## 功能

- **三种练习模式**
  - 标点定位：成对练习英文标点，再过渡到中文标点
  - 英文短句：练习大小写、空格与标点混排
  - 中文短句：使用你熟悉的输入法，按提交上屏的字符计分
- **易错复习**：按最近 12 轮中首次打错的字符统计排序，自动生成针对性题目
- **键位提示**：可视化 QWERTY 键盘高亮当前目标键，支持中文标点映射提示，可一键关闭
- **成绩指标**：首次命中率、标点首次命中、错输次数
- **本地记录**：练习记录保存在浏览器 `localStorage`，最多保留 50 轮，界面展示最近 4 轮
- **输入法友好**：通过 `compositionstart` / `compositionend` 处理中文输入法组合输入，未确认的候选不计分

## 快速开始

```bash
# 方式一：直接双击打开
open index.html

# 方式二：起一个本地静态服务器（推荐，便于页面路径固定、记录连续）
python3 -m http.server 8000
# 然后访问 http://localhost:8000
```

无需安装依赖，无需构建。用桌面浏览器打开，配美式 QWERTY 实体键盘体验最佳。

## 使用方法

1. 选择练习模式，关闭「显示提示」，点「重练本题」开始一轮
2. 按顺序输入上方题面（`␣` 表示一次空格）
3. 输错时光标停在原处，直接重打即可
4. 完成一轮后到「练习易错键」复习，或点「下一题」继续
5. 详细的训练节奏、标点记忆方法和指标解释见 [训练方案.md](训练方案.md)

## 计分规则

- **首次命中率** = 首次输入即正确的位置数 ÷ 尝试过的位置数
- **标点首次命中** 单独统计命中数与样本数
- **错输次数** 统计实际失败的尝试，同一位置错多次会累加
- 中文以输入法提交的字符为单位逐字比对，拼音候选未确认时不计分
- 有提示与无提示的成绩分开比较；未完成的练习不存档

## 浏览器支持

建议使用较新版本的 Chrome、Edge、Safari 或 Firefox。代码使用了 `Object.hasOwn`、Unicode 属性转义正则（`\p{P}`）等现代特性。若浏览器禁用了本地存储，练习记录仅在当前页面内保留。
